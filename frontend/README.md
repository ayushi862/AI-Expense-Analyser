# AI Expense Analyser — Frontend

Responsive React dashboard built with Vite, Tailwind CSS, React Router, Lucide
icons, and Recharts. The dashboard currently uses sample data; no backend
services are connected.

## Run locally

From this `frontend` directory:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Check the application

```bash
npm run lint
npm run build
```

To try the dashboard interactions, use **Add expense**, search transactions,
open **Upload statement** to select a local file, and use the sidebar or
**View all transactions** link to navigate. Other navigation destinations are
placeholders for future pages.
